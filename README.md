# Telli Jeswar Kalyan — Portfolio Website

A responsive personal portfolio website built with plain HTML and CSS, ready for GitHub Pages.

## Preview locally

Open `index.html` in any modern browser.

## Publish with GitHub Pages

1. Create a GitHub repository named `jeswarkalyan.github.io` (or another repository name).
2. Upload `index.html` and this `README.md` to the repository root.
3. Open **Settings → Pages** in the repository.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site.

If you use a repository named `jeswarkalyan.github.io`, the site URL will be `https://jeswarkalyan.github.io/`. For another repository name, the URL will include that repository name.

## Before publishing

- Add your professional email and LinkedIn URL in the Contact section.
- Add repository links for projects that are not yet published.
- Verify education dates and project descriptions.
- Add a downloadable PDF resume if you want a resume button.
